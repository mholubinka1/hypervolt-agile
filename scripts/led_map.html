Hypervolt LED Map

Run scripts/calibrate_leds.py against the real charger, watch which physical position lights up for each printed index, and type what you observed into the matching row below (or click its dot on the diagram to jump there). Labels save to this browser automatically as you type. When you're done, click Export and commit the downloaded JSON alongside this file as the permanent record.

Outer ring: indices 0–38 (39 LEDs), anticlockwise from top-right.
Lightning bolt: indices 39–50 (12 LEDs), bottom to top.
Filled-in labels turn their dot red.

Labels persist to this browser's local storage only — they are not shared between devices or browsers, and clearing site data removes them. Export regularly once you start filling labels in, and commit the result to the repo so the map survives independently of any one browser's storage.
