Hypervolt LED Map

Run scripts/calibrate_leds.py against the real charger. Each time it prints Index N, find the dot on the diagram at the physical position that just lit up and type N into it. The diagram is drawn to the Hypervolt Home 3's real body size (243 × 328 mm), so every dot's exported coordinates are true millimetres. Entries save to this browser as you type. When you're done, click Export and commit the downloaded JSON alongside this file as the permanent record.

Ring: positions ring-0–ring-38, anticlockwise from top-right.
Bolt: positions bolt-0–bolt-11, bottom to top.
A dot fills red once it holds a value. An orange box means that value is out of range (0–50) or a duplicate — it's flagged, not blocked.
Exported x/y are millimetres from the charger body's top-left corner.

Entries persist to this browser's local storage only — they are not shared between devices or browsers, and clearing site data removes them. Export regularly, and commit the result to the repo so the map survives independently of any one browser's storage.
